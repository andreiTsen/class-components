# Pokemon Search

Next.js App Router application for searching Pokemon, viewing server-rendered
details, switching locales, selecting items, and exporting selected data as CSV.

## Stack

- Next.js App Router
- TypeScript
- React
- Redux Toolkit
- next-intl
- Vitest

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
npm test
```

## Features

- Locale-aware routing for English and Russian.
- Shared application layout.
- Server-rendered search results and detail pages.
- Static About page.
- Server-side CSV export route.
- Optimized images with `next/image`.
